## Introduction

Fred Weinhaus has been a pivotal figure in the ImageMagick community, providing a wealth of scripts and tools that enhance image processing capabilities. This repository aims to preserve his work and make it accessible offline for users who wish to utilize these powerful scripts without relying on an internet connection.

## Usage

To use the scripts in this repository, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/felipefacundes/fred_site_offline.git ~/.fred_site_offline
   ```

2. **Navigate to the Directory**:
   ```bash
   cd freds-imagemagick-scripts
   ```

3. **Run a Script**:
   - Each script can be executed using the command line. For example, to use the `glow` script:
   ```bash
   glow [-a amount] [-s softening] infile outfile
   ```

4. **Refer to the Documentation**: Each script includes usage instructions and examples. Please refer to the comments within the scripts for detailed information.
